# Research records

This directory contains lightweight project state, not raw experiment output.

`STATE.md` is the shared human-approved current research state.

As the project grows, add:

```text
research/
├── STATE.md
├── questions/
├── hypotheses/
├── experiments/
└── decisions/
```

Research notebooks and code remain under the repository's normal `notebooks/`, `src/`, `tests/`, and configuration paths.

Obsidian remains the main store for the researcher's personal learning notes, literature synthesis, quizbook, and derivations.
